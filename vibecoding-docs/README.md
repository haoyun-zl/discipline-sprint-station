# 自律冲刺站

一个面向个人生活规划与自律养成的响应式网页工具，支持电脑端、移动端和 PWA 安装。  
它把日常打卡、周奖励、长期成长、角色养成和公开部署整合在一起，让“坚持”不只是记账，而是更有反馈感的养成过程。

## 项目概览

- 项目名称：`自律冲刺站`
- 技术栈：`HTML + CSS + JavaScript`
- 数据存储：浏览器 `LocalStorage`
- 适配平台：桌面浏览器、手机浏览器、PWA
- 当前公开地址：`https://haoyun-zl.github.io/discipline-sprint-station/`
- 当前仓库地址：`https://github.com/haoyun-zl/discipline-sprint-station`

## 核心设计

这个项目采用双结算机制，把短期激励和长期成长拆成两条并行反馈线：

- 周结算：每周一重新开始累计，用来兑换现实奖励
- 累计结算：从开始使用的第一天永久累计，用来驱动角色成长和等级提升

这样做的目的，是让用户既能获得“这周就有结果”的即时动力，也不会因为某一周状态波动而觉得前面的努力白费。

## 打卡模块

每日积分来自五个模块：

- 游泳：`20` 分
- 健身：`20` 分
- 练习口语：`30` 分
- 秋招准备：`每 1 小时 10` 分，可累计
- 12 点前睡觉：`20` 分
- 开心快乐不焦虑：`10` 分

页面支持按日期打卡，保存后会同步刷新：

- 当日积分
- 所在周积分
- 累计总积分
- 当前连续打卡 `streak`
- 角色等级与成长状态
- 历史周记录

## 奖励机制

### 周奖励

- 周一到周六正常累计积分
- 周日为“奖励日 / 还债日”
- 达到 `360` 分：可兑换一次攀岩
- 达到 `420` 分：可兑换一次豪华放纵餐
- 若分数不足，可以在周日继续完成任务补分冲线

### 累计等级

累计积分从第一天开始永久保存，当前等级节点如下：

- `L0`：0
- `L1`：2000
- `L2`：5000
- `L3`：8000
- `L4`：12000
- `L5`：16000
- `L6`：20000

## 角色养成

用户首次进入时可选择一个养成伙伴：

- 大树
- 乌龟
- 小猫

角色选择不会影响积分规则，但会影响视觉表现与互动体验。当前版本已支持：

- 角色初次选择与后续切换
- 随累计积分变化的成长阶段
- 发光、触摸反馈、舞台光效
- 更可爱的角色视觉风格
- 点击互动反馈，例如摸摸头、摇尾巴、点头、发光等

## PWA 能力

项目支持基础 PWA 使用体验：

- 安装到桌面
- 独立窗口启动
- 离线缓存已访问页面
- 应用图标与清单配置

安装方式：

- 安卓 Chrome / Edge：打开站点后选择“安装应用”或“添加到主屏幕”
- iPhone Safari：点击“分享”后选择“添加到主屏幕”

注意：

- PWA 安装能力通常需要通过站点地址访问
- 直接双击本地 `index.html` 可以使用基础功能，但通常不会显示完整安装入口

## 数据说明

当前版本是 `local-first` 方案，默认把数据保存在用户自己的浏览器里。

这意味着：

- 刷新页面后数据不会丢
- 不同浏览器之间默认不会自动同步
- 清除浏览器缓存或更换设备后，数据可能不可见
- 项目支持导出和导入 JSON 用于手动备份

当前版本还预留了账号体系与云同步接入层。完成云端配置后，可以支持：

- 邮箱注册 / 登录
- 手动同步到云端
- 从云端拉取数据
- 自动同步开关
- 多设备同步

具体配置方式见：

- `CLOUD_SYNC_SETUP.md`

## 文件结构

主要文件如下：

- `index.html`：页面结构
- `styles.css`：界面样式与动画
- `script.js`：积分、角色、打卡、历史记录等交互逻辑
- `cloud-config.js`：账号体系与云同步前端配置
- `manifest.webmanifest`：PWA 清单
- `sw.js`：离线缓存脚本
- `DEPLOY.md`：部署说明
- `CLOUD_SYNC_SETUP.md`：账号体系与云同步配置说明
- `vercel.json`：Vercel 部署配置
- `netlify.toml`：Netlify 部署配置
- `.nojekyll`：GitHub Pages 兼容文件
- `robots.txt`：搜索引擎抓取规则
- `sitemap.xml`：站点地图

## 本地使用

### 直接打开

1. 打开 `index.html`
2. 选择角色
3. 选择日期并填写当天完成情况
4. 点击“保存今天的打卡并喂养角色”

### 本地服务预览

如果你希望完整体验 PWA 或更接近线上环境，建议用本地静态服务打开项目目录。

例如：

```bash
python3 -m http.server 8124
```

然后访问：

```text
http://127.0.0.1:8124/
```

## 账号依赖说明

当前公开地址托管在 GitHub Pages 上，因此长期可用性主要依赖：

- GitHub 账号仍然存在
- 仓库仍然存在
- 仓库保持公开
- GitHub Pages 没有被关闭

邮箱本身不是网页运行时依赖，但如果邮箱失效导致 GitHub 账号无法恢复，链接的长期稳定性也会受到影响。
